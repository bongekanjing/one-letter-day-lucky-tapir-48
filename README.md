## The entry

> Q

Q stands for **Queue**.

## Run it

```sh
python3 -P -s main.py
```

Writes `$MAKEFUN_OUTPUT_DIR/entry.txt`, or `./entry.txt` when unset. The
destination directory is created if it does not exist. Standard library only.

## Why Q

1. It has to stand for a word that describes a day, and it does: Queue.
2. The word is vivid and specific rather than a mood. A queue is a place, with
   a shape and a length and a view of the back of someone's head, so the day
   arrives as one picture instead of an adjective.
3. It is funny the moment it lands, because the joke is the gap between one
   letter and an entire day spent shuffling forward. Q is also the one letter
   that is never alone and rarely starts anything, so an entry of just Q reads
   as a queue of one.
4. It is true. Most days are some queue — of builds, of tickets, of people —
   so the letter reports the day rather than performing an emotion about it.
5. The letter suits the word: it is the word's own initial, its tail reads like
   a line of people, and the obvious picks are M, F and T. Q is the sharper
   initial nobody reaches for, and the word behind it is unmistakable.
